# 電波人間 QRコード管理ツール

「New 電波人間のRPG FREE!」のQRコードや電波人間の情報を管理するための、非公式のファン制作Webツールです。

## ⚠️ 開発・サービス終了のお知らせ

「New 電波人間のRPG FREE!」が2026年12月7日をもってサービス終了となることが発表されたため、本ツールも開発を終了することとしました。

今後、本サイトはゲームのサービス終了に合わせて提供を終了する予定です。

これまで本サイトをご利用いただいた皆さま、ありがとうございました。

本リポジトリは、開発記録およびアーカイブとして今後も公開します。

## 🌐 公開サイト

https://toshi0703.github.io/denpa-qr-web/

## 📖 このサイトについて

本サイトでは、電波人間の情報やQRコードをブラウザ上で管理できます。

主な機能は以下のとおりです。

- 電波人間の情報登録
- 登録した電波人間の一覧表示
- 電波人間の検索
- 登録データの編集・削除
- 捕獲済み・お気に入り管理
- QRコード画像の保存・表示
- QRコード生成履歴の管理
- 登録データのバックアップ・復元
- 検索条件の保存
- 出生ルートの登録（開発中）

## 💾 データの保存について

登録した電波人間の情報やQRコード画像などのデータは、原則として利用者のブラウザ内に保存されます。

そのため、ブラウザのデータを削除した場合などには、登録データが失われる可能性があります。

また、本サイトはサービス終了に伴い提供を終了する予定です。

必要なデータがある場合は、サイトの提供終了前にサイト内のバックアップ機能を利用して保存してください。
